# Лабораторный практикум: «Проектирование схемы БД с использованием CASE-средств и аудит безопасности прикладных АИС»

Учебный проект по знакомству с защитой проекта от глупых решений

В этои проекте нет ошибок в коде есть только **архитектурные** ошибки которые были допущены намерено и ваша главная задача устранить данные ошибки и рассмотреть типизированные ошибки на проекте.

## Требования для запуска
* Visual Studio 2026
* Платформа .NET 10.0 или выше
* Установленный через NuGet пакет Microsoft.EntityFrameworkCore.Sqlite

## Как запустить проект:
1. Скопируйте ссылку https://github.com/odium22/case-tamplate
2. Откройте Visual Studio
3. Нажмите на кнопку Клонирование репозитория и нажмите на саму кнопку
4. Вставьте ссылку
5. Откройте файл решения (.sln или .slnx).
6. Нажмите комбинацию клавиш Ctrl + F5 (запуск без отладки).
7. Программа автоматически создаст файл базы данных ef_university.db, заполнит его начальными данными и по очереди выполнит примеры работы с EF Core.

## Структура проекта
* Models - классы данных (сущности)
* Data — настройка подключения и данных
* Demos — практические сценарии работы с заданием.
* Program.cs — точка входа, главное прога которая всё запускает.
